================================================================================
PART A -- CONFIRM KD EFFICIENCY IS EQUAL IN MALES vs FEMALES (from bulk data)
================================================================================

THE LOGIC
  KAT8-KD lowers Kat8 mRNA. If females knock down Kat8 LESS than males, the
  entire "female protection" story could be a trivial dose artifact (less
  knockdown = less phenotype). You can test this directly in the data you
  already have, BEFORE any wet-lab work. Three nested checks:

CHECK A1 -- Per-sex Kat8 log2 fold change (eyeball + effect size)
  Pull Kat8's own KD logFC from the per-sex DESeq2 you already ran (de_m,
  de_f). If KD efficiency is equal, m_lfc and f_lfc for Kat8 should be
  similar (both strongly negative) with overlapping standard errors.

  HYPOTHESIS (A1):
    H0: Kat8 KD log2FC is the same in males and females (equal knockdown).
    H1: Kat8 KD log2FC differs by sex (unequal knockdown -> confound).
  PREDICTION IF MODEL IS CLEAN: both sexes ~ equal, large negative logFC.

CHECK A2 -- Formal: is Kat8 ITSELF a Sex:Genotype interaction gene?
  This is the elegant version. You already fit
  ~ Sex + Genotype + Sex:Genotype. Just read off the interaction statistic
  for the single gene Kat8. If Kat8 is NOT a significant interaction gene,
  knockdown is statistically equal across sex. If it IS, efficiency is
  sex-biased and you must control for it (covariate, or report the dose).

CHECK A3 -- Per-sample Kat8 "dose" plot
  Normalized Kat8 counts per sample, faceted by Sex x Genotype. This shows
  whether any single replicate (e.g. one weak-KD female) is driving things,
  and whether residual Kat8 differs by sex even if the fold change matches.

CAVEAT YOU MUST STATE TO THE PI
  - mRNA knockdown is a PROXY for protein KAT8 and for the H4K16ac mark.
    Equal mRNA KD does not guarantee equal H4K16ac loss (translation/
    half-life can differ). The definitive control is still WB / H4K16ac
    IF or CUT&RUN by sex (your TODO-0A). The bulk check can only RULE OUT
    a gross mRNA-level confound -- which is still worth doing first.
  - If the model is a floxed-exon Cre deletion (not shRNA), featureCounts
    may still count untargeted exons; confirm by looking at the deleted
    region specifically, or trust the functional H4K16ac readout instead.

================================================================================
PART B -- THE RIGOROUS WAY TO SHOW "FEMALE REACTION > MALE REACTION"
================================================================================

FRAMING (important for the PI)
  "The female response is larger" is a statement about INTERACTION-MAGNITUDE
  ASYMMETRY. It is NOT about number of DEGs (that is power-dependent; in your
  gWAT Venn males actually have MORE DEGs: 730 unique vs 450). The defensible
  claim is: "Among genes that respond to KD -- and specifically within the
  PPARgamma/lipid program -- females show LARGER-magnitude fold changes than
  males." Four complementary tests, weakest-to-strongest evidence stacked:

----------------------------------------------------------------------
TEST B1 -- Paired |logFC| on shared DEGs  (THE CORE TEST)
----------------------------------------------------------------------
  For every gene significant in EITHER sex, compare |female logFC| vs
  |male logFC| as a PAIRED difference, and test the median against 0 with a
  Wilcoxon signed-rank test (robust, non-parametric, no distributional
  assumptions).

  HYPOTHESIS (B1):
    H0: median(|F logFC| - |M logFC|) = 0  (symmetric response)
    H1: median(|F logFC| - |M logFC|) > 0  (female response larger)
  WHAT TO TELL PI: "On shared knockdown-responsive genes, females show a
    median per-gene fold-change magnitude X% larger than males (Wilcoxon
    signed-rank p = ...)." This is one number + one p-value. Clean.
  HONEST CAVEAT: estrous-driven female variance INFLATES noise and tends to
    DEFLATE female |logFC| estimates, so if anything this test is
    conservative against your hypothesis -- a positive result is strong.

----------------------------------------------------------------------
TEST B2 -- Orthogonal (Deming) regression slope, female ~ male
----------------------------------------------------------------------
  Fit a total-least-squares line through the M-vs-F logFC scatter (shared
  DEGs). Slope > 1 means the female axis is "stretched" relative to male =
  female-amplified. Report slope + bootstrap 95% CI. Ordinary regression is
  WRONG here (both axes have error); use Deming/orthogonal.

  HYPOTHESIS (B2):
    H0: slope = 1 (equal gain).   H1: slope > 1 (female amplified).
  WHAT TO TELL PI: "The female-vs-male response slope is 1.2 (95% CI
    1.1-1.3), i.e. females mount a ~20% larger transcriptional response per
    unit male response." Gives an effect size, not just significance.

----------------------------------------------------------------------
TEST B3 -- Total response magnitude / multivariate displacement
----------------------------------------------------------------------
  Per sex, compute the Euclidean length of the logFC vector across the
  union of DEGs (or across the PPAR module in B4). Bootstrap genes for a CI.
  This captures "how far from control did the transcriptome move," summed.

  HYPOTHESIS (B3):
    H0: ||F response|| = ||M response||.   H1: ||F response|| > ||M response||.
  WHAT TO TELL PI: "The total transcriptional displacement induced by KD is
    larger in females (bootstrap CI excludes equality)." Good single
    summary figure (two bars + CIs).

----------------------------------------------------------------------
TEST B4 -- Targeted PPARgamma-Glut4 MODULE score  (ties to the het paper)
----------------------------------------------------------------------
  This is the most mechanistically meaningful and the one the PI will like
  most, because it connects directly to the Pessoa/Akhtar MOF->Pparg->Glut4
  axis. Build a fixed gene set (below), compute a per-SAMPLE module score
  (mean z-scored expression), and fit Sex x Genotype on the score. The
  interaction term IS the sex-difference-in-response, on the exact pathway
  the field already accepts as the KAT8 effector.

  MODULE (from Pessoa Rodrigues 2021, the established MOF->PPARg->GLUT4 axis):
    Core:        Pparg, Ppargc1a (Pgc1a), Mef2c, Slc2a4 (Glut4)
    PPARg targets/storage: Cd36, Fabp4, Lpl, Plin1, Plin4, Cidec, Adipoq,
                  Scd1, Lipe (Hsl), Pnpla2 (Atgl)
    Counter-marker: Rbp4 (UP when Glut4 down -- insulin resistance marker)

  HYPOTHESIS (B4):
    H0: KD reduces the PPARg-Glut4 module equally in both sexes.
    H1: KD reduces (or the females defend) the module to a DIFFERENT degree
        by sex (significant Sex:Genotype on the module score).
  WHAT TO TELL PI: "On the canonical MOF->PPARgamma->GLUT4 module that the
    field has established as the KAT8 effector, the sex x genotype
    interaction is significant (p = ...), with females [defending /
    over-responding]. This localizes the sex effect to the known mechanism,
    not a novel pathway." This is your headline sentence.

----------------------------------------------------------------------
DIRECTIONALITY -- the nuance you MUST resolve (don't let it bite you)
----------------------------------------------------------------------
  In iWAT your dominant interaction class is "Male-buffered / Female-
  amplified" but in the DOWN direction (both sexes down, females MORE down).
  "Female reacts more" is therefore: females downregulate the lipid/PPAR
  program more strongly. Whether that is PROTECTIVE or HARMFUL cannot be
  read from magnitude alone -- it must be anchored to phenotype. Two models
  to put to the PI explicitly:

    MODEL 1 (active compensation): females mount a LARGER, coordinated
      remodeling (e.g. more browning / oxidative compensation) that
      protects them. Larger response = adaptive.
    MODEL 2 (over-shoot is incidental): the larger female change is a
      passive consequence of higher baseline expression of these genes in
      females, not protective per se.
  DISCRIMINATING TEST: split the module by direction (up-genes vs down-
  genes) and ask whether the female-amplified set is enriched for
  thermogenic/oxidative (browning) genes (Ucp1, Ppargc1a, Cidea, Elovl3,
  Cox7a1, Cpt1b). If yes -> Model 1 (compensation). Pair with phenotype.

-------- DROP-IN CODE: Part B (run inside the depot loop, after de_m/de_f) --

## Shared DEG frame (either-sex significant) for B1-B3
shared <- merge(
  de_m[, c("gene","log2FoldChange","padj")],
  de_f[, c("gene","log2FoldChange","padj")],
  by = "gene", suffixes = c("_m","_f"))
shared <- shared[is.finite(shared$log2FoldChange_m) &
                 is.finite(shared$log2FoldChange_f), ]
shared$deg_either <- (!is.na(shared$padj_m) & shared$padj_m < fdr_cut) |
                     (!is.na(shared$padj_f) & shared$padj_f < fdr_cut)
deg <- shared[shared$deg_either, ]

## --- B1: paired Wilcoxon on |logFC| ---
mag_diff <- abs(deg$log2FoldChange_f) - abs(deg$log2FoldChange_m)
b1_p   <- wilcox.test(mag_diff, mu = 0, alternative = "greater")$p.value
b1_med <- median(mag_diff)
cat(sprintf("[B1] %s: median(|F|-|M|)=%.3f log2 units, Wilcoxon greater p=%.2e (n=%d DEGs)\n",
            depot, b1_med, b1_p, nrow(deg)))

## --- B2: Deming/orthogonal slope (PC of the 2D scatter), bootstrap CI ---
deming_slope <- function(x, y) {
  v <- prcomp(cbind(x, y))$rotation[, 1]; v[2] / v[1]
}
b2_slope <- deming_slope(deg$log2FoldChange_m, deg$log2FoldChange_f)
set.seed(1)
b2_boot <- replicate(2000, {
  i <- sample(nrow(deg), replace = TRUE)
  deming_slope(deg$log2FoldChange_m[i], deg$log2FoldChange_f[i])
})
cat(sprintf("[B2] %s: female~male slope=%.3f (95%% CI %.3f-%.3f); >1 => female amplified\n",
            depot, b2_slope, quantile(b2_boot,.025), quantile(b2_boot,.975)))

## --- B3: total response magnitude per sex, bootstrap ---
mag_vec <- function(v) sqrt(sum(v^2))
b3_m <- mag_vec(deg$log2FoldChange_m); b3_f <- mag_vec(deg$log2FoldChange_f)
b3_boot <- replicate(2000, {
  i <- sample(nrow(deg), replace = TRUE)
  mag_vec(deg$log2FoldChange_f[i]) - mag_vec(deg$log2FoldChange_m[i])
})
cat(sprintf("[B3] %s: ||F||=%.1f vs ||M||=%.1f; diff 95%% CI %.1f-%.1f\n",
            depot, b3_f, b3_m, quantile(b3_boot,.025), quantile(b3_boot,.975)))

## --- B4: PPARg-Glut4 module score, Sex x Genotype interaction ---
ppar_module <- c("Pparg","Ppargc1a","Mef2c","Slc2a4","Cd36","Fabp4","Lpl",
                 "Plin1","Plin4","Cidec","Adipoq","Scd1","Lipe","Pnpla2","Rbp4")
mod <- intersect(ppar_module, rownames(depot_counts))
if (length(mod) >= 4) {
  dds_mod <- DESeqDataSetFromMatrix(round(depot_counts), depot_annot, ~ 1)
  dds_mod <- estimateSizeFactors(dds_mod)
  vsd <- log2(counts(dds_mod, normalized = TRUE) + 1)
  z   <- t(scale(t(vsd[mod, , drop = FALSE])))          # gene z-scores
  score <- colMeans(z, na.rm = TRUE)                    # per-sample module score
  md <- data.frame(score = score,
                   Sex = depot_annot[names(score),"Sex"],
                   Genotype = depot_annot[names(score),"Genotype"])
  fit  <- lm(score ~ Sex * Genotype, data = md)
  b4_p <- summary(fit)$coefficients
  cat(sprintf("[B4] %s: PPARg-Glut4 module Sex:Genotype interaction p=%.3g (genes used=%d)\n",
              depot, tail(b4_p[,4],1), length(mod)))
  p_mod <- ggplot(md, aes(Genotype, score, fill = Genotype)) +
    geom_boxplot(outlier.shape = NA, alpha=.5) + geom_jitter(width=.15) +
    facet_wrap(~Sex) +
    labs(title=paste0(depot,": PPARgamma-GLUT4 module score"),
         subtitle="Pessoa/Akhtar MOF->Pparg->Glut4 axis",
         y="module z-score") + theme_bw()
  ggsave(file.path(sex_dir, paste0("PPARmodule_", depot, "_", run_tag, ".png")),
         p_mod, width=7, height=4, dpi=150)
  write.csv(md, file.path(tables_dir, paste0("PPARmodule_scores_", depot, "_", run_tag, ".csv")))
}
